# 使用说明

## 首次登录

安装后从飞牛桌面打开“风栖”，使用安装向导中设置的密码登录。新风扇组初始处于监测状态，不会自动改写 PWM。概览页显示运行状态、CPU 与硬盘温度、温度走势、实体风扇转速和硬盘温度。

应用只管理 Linux 系统通过 `hwmon` 暴露的接口。接口名称、数量和可写状态取决于主板与内核驱动；若没有发现 PWM，应用仍可作为监控面板使用。

## 安全地识别 PWM 与 FAN 的对应关系

RPM 输入用于建立初始 FAN 列表；PWM 输出是可单独调节的接口。系统不能仅凭接口编号可靠推断某路 PWM 控制哪把实体风扇，因此要逐路测试：

1. 在“风扇与温控”页面的 PWM 接口区，选一条未接管的 PWM，点击“测试”。
2. 该输出会临时设置为全速；测试持续 10 秒并自动恢复原状态，也可提前结束。
3. 观察所有 FAN 的 RPM 读数和实体风扇声音，确认受影响的是哪把风扇。
4. 点击“添加到 FAN”，选择对应实体风扇并确认。测试本身不会自动分配。
5. 对下一条 PWM 重复操作。确认映射前不要同时测试多路未知输出。

正在接管、测试中或待恢复的 PWM 不能随意改归属。忽略 PWM 后，应用不会读取、检查、测试或控制这条接口。

## FAN 控制模式

每个 FAN 有三个运行模式：

- **温控**：默认跟随全局温控曲线；需要时可以为单个 FAN 设独立温度来源与曲线。
- **全速**：把归属此 FAN 的 PWM 设置为 100%。
- **手动**：设置 25–100% 占空比，默认手动值为 50%。占空比不是风扇 RPM 的百分比。
- **释放接管**：停止该 FAN 的应用控制，并尝试恢复接管前记录的硬件模式和值。

全局温控曲线选择 CPU 温度、最高磁盘温度或两者最高值作为温度来源，可编辑曲线节点。曲线末端温度和占空比可自定义；70°C 不会被固定为全速。忽略的温度节点不参与对应曲线的读数选择和平均值。概览支持分别忽略 CPU 或硬盘来源，硬盘也可逐个设置。

高温建议卡片只提醒，不会自行接管风扇；需要用户点选应用建议方案或忽略。重启时应用恢复已保存的 FAN 模式；某组恢复失败会隔离该组并提示待恢复状态，不会把失败误报成成功。

## 温度走势

- 使用 **5 分钟**与 **30 分钟**两个范围。服务刚启动、历史记录尚短时，两档可显示相同的已有数据。
- 曲线显示弹窗可开关 CPU 平均、硬盘平均和各个温度节点；忽略来源不会显示，也不计入平均。
- 平均线分别为红色（CPU）和蓝色（硬盘）实线；单节点使用独立颜色的虚线。
- 鼠标悬停显示该采样时间下所有开启曲线的温度。曲线设置只改变图表显示，不会改风扇控制。

## 异常处理

- **PWM 无法控制**：检查系统是否加载了兼容驱动、PWM 是否可写，以及是否被其它服务或 BIOS 接管。
- **待恢复**：打开对应 PWM 的“重试恢复”。如果驱动拒绝写入，先检查驱动和主板状态；不要通过清空记录掩盖硬件仍未恢复的问题。
- **RPM 不变化**：观察风扇声音和物理风扇响应。某些分线器只回传一路测速信号；软件不会根据 PWM 编号推断接线。
- **硬盘无温度**：应用优先读 hwmon；若系统提供 `smartctl`，可能在硬盘未休眠时读取 SMART。没有可用读数时，页面会显示当前状态。
